# Panduan Teks & Copywriting (Anti-Slop) — CariKostKita Landing Page

- **Prinsip Utama**: Bahasa Indonesia alami, hangat, transparan, dan tidak menggunakan kata klise AI (*anti-slop*).
- **Target Pembaca**: Mahasiswa dan perantau di Kota Pekanbaru serta bapak/ibu pemilik kost.

---

## 1. Aturan Penulisan (Writing Rules)

1. **Hindari Kata Klise AI**:
   - Dilarang menggunakan kata: *revolusioner, mutakhir, mahakarya, seamless, solusi terbaik masa kini, tak tertandingi, melesat*.
   - Gunakan kata nyata yang menjelaskan fungsi: *cepat, ringan, foto asli, langsung ke pemilik, titik lokasi tepat*.
2. **Jujur Mengenai Wilayah Operasional**:
   - Sebutkan secara jelas bahwa aplikasi ini berfokus pada area **Kota Pekanbaru** (khususnya wilayah sekitar kampus UIR, UNRI, UIN Suska, dan Kecamatan Bukit Raya).
3. **Penjelasan Teknis Ramah Pemula**:
   - Istilah "Install dari Sumber Tidak Dikenal" (*Install Unknown Apps*) dijelaskan sebagai prosedur baku Android untuk aplikasi pra-rilis, bukan indikasi bahwa file tersebut berbahaya.
4. **Gaya Bahasa**:
   - Lugas, santun, terstruktur, dan tidak bertele-tele.

### 2.4 Seksi Fitur Unggulan (Core Features)
- **Judul Seksi**: Fitur yang Kami Bangun untuk Memudahkan Anda
- **Deskripsi**: Kami merancang CariKostKita sesederhana mungkin agar mahasiswa dan pencari kost tidak kebingungan saat mencari tempat tinggal.

#### Fitur 1: Sistem 3 Peran yang Jelas & Terpisah
- **Deskripsi**: Peran Pencari Kost, Pemilik Kost, dan Administrator dibedakan secara tegas. Pemilik kost harus melewati proses verifikasi identitas terlebih dahulu sebelum dapat mengunggah kamar, sehingga meminimalkan risiko penipuan kost fiktif.

#### Fitur 2: Alamat Lengkap & Koordinat Google Maps Presisi
- **Deskripsi**: Setiap kost dilengkapi alamat detail hingga nama jalan, kelurahan, kecamatan, patokan jalan yang mudah dikenali, serta tombol satu klik untuk membuka rute navigasi di Google Maps.

#### Fitur 3: Galeri Multi-Foto Kamar
- **Deskripsi**: Lihat foto tampak depan, dalam kamar, kamar mandi, hingga fasilitas bersama sebelum memutuskan untuk survei langsung ke lokasi.

#### Fitur 4: Hubungi Pemilik Langsung
- **Deskripsi**: Kirim pesan langsung lewat fitur obrolan di aplikasi atau buka tautan WhatsApp pemilik kost dengan satu ketukan tombol.

#### Fitur 5: Fitur Lapor Kost
- **Deskripsi**: Jika Anda menemukan kost yang foto, harga, atau lokasinya tidak sesuai dengan kenyataan di lapangan, Anda dapat langsung melaporkannya agar tim kami menindaklanjuti.

### 2.5 Seksi Panduan Instalasi APK Android
- **Judul Seksi**: Cara Memasang File APK di HP Android Anda
- **Deskripsi**: Karena aplikasi ini masih dalam tahap uji coba publik sebelum tayang di Google Play Store, Android akan meminta izin instalasi sekali saja. Ikuti 4 langkah mudah berikut:

1. **Langkah 1: Unduh File APK**
   - Tekan tombol **Download APK** di halaman ini. Tunggu hingga proses pengunduhan selesai pada bilah notifikasi Anda.
2. **Langkah 2: Buka Berkas Unduhan**
   - Tarik bilah notifikasi HP Anda lalu ketuk file `CariKostKita.apk`, atau buka aplikasi **Pengelola File (File Manager)** lalu masuk ke folder **Download**.
3. **Langkah 3: Izinkan Penginstalan**
   - Jika muncul peringatan keamanan *"Demi keamanan, ponsel Anda tidak diizinkan memasang aplikasi dari sumber ini"*, pilih opsi **Setelan / Pengaturan (Settings)**, lalu aktifkan centang **Izinkan dari sumber ini**.
   - *Catatan: Ini adalah dialog standar Android untuk file yang dipasang di luar Play Store.*
4. **Langkah 4: Pasang dan Selesai**
   - Tekan tombol **Instal (Install)**. Tunggu beberapa detik hingga proses selesai, lalu buka aplikasi CariKostKita dan mulai mencari kost.

### 2.6 Seksi Khusus Pemilik Kost (Owner Onboarding)
- **Judul**: Anda Punya Kost di Pekanbaru?
- **Subjudul**: Daftarkan kost Anda sekarang agar dilihat oleh ribuan mahasiswa dan calon penyewa di Pekanbaru.
- **Langkah Pendaftaran**:
  1. Unduh dan pasang aplikasi CariKostKita.
  2. Buka menu **Profil**, lalu pilih **Daftar sebagai Pemilik Kost**.
  3. Isi identitas dan data kost Anda dengan lengkap (nama kost, alamat, patokan, fasilitas, dan foto).
  4. Tim pengembang kami akan memverifikasi data Anda dalam waktu 1x24 jam.
  5. Setelah status akun disetujui, kost Anda akan langsung tampil di halaman pencarian utama.
- **Tombol**: *Unduh Aplikasi untuk Pemilik*

### 2.8 Seksi Tanya Jawab (FAQ)

#### Q1: Mengapa aplikasi ini belum ada di Google Play Store?
> **Jawaban**: CariKostKita saat ini sedang berada dalam tahap pengujian publik awal (*open beta*). Kami merilis berkas APK terlebih dahulu agar teman-teman mahasiswa dan pemilik kost di Pekanbaru dapat langsung mencoba dan memberikan masukan sebelum aplikasi dipublikasikan secara resmi di Google Play Store.

#### Q2: Apakah aman menginstal file APK ini di HP saya?
> **Jawaban**: Ya, sangat aman. File APK ini dibuat langsung dari repositori resmi proyek kami tanpa disisipi iklan berbahaya, malware, maupun pelacak data sensitif. Aplikasi hanya meminta izin dasar yang dibutuhkan fitur aplikasi seperti lokasi dan akses penyimpanan untuk upload foto.

#### Q3: Berapa versi Android minimal yang diperlukan?
> **Jawaban**: Aplikasi CariKostKita dapat berjalan lancar di smartphone dengan sistem operasi **Android 8.0 (Oreo)** hingga versi **Android 14 ke atas**.

#### Q4: Apakah mencari kost di aplikasi ini dikenakan biaya?
> **Jawaban**: Tidak. Aplikasi CariKostKita 100% gratis untuk pencari kost. Anda tidak dipungut biaya langganan, biaya admin, maupun biaya komisi perantara.

#### Q5: Bagaimana jika saya lupa mengizinkan instalasi dari sumber tidak dikenal?
> **Jawaban**: Anda dapat membuka menu **Pengaturan HP > Aplikasi > Akses Aplikasi Khusus > Pasang Aplikasi yang Tidak Dikenal**, lalu pilih browser yang Anda gunakan untuk mengunduh (misalnya Google Chrome) dan aktifkan izinnya.

#### Q6: Saya pemilik kost, apakah saya langsung bisa mengunggah kost setelah registrasi?
> **Jawaban**: Untuk menjaga keamanan pencari kost dan mencegah penipuan fiktif, setiap pengajuan pemilik kost akan ditinjau dan diverifikasi terlebih dahulu oleh tim admin kami sebelum kost Anda dapat ditayangkan ke publik.
